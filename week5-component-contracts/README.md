This folder contains my Week 5 component contract work for Borrowly, a platform that helps college students borrow academic essentials instead of purchasing them.

The three reusable React components are:

1. Item Listing Card — Displays item details, condition, owner, availability, borrowing duration, and collection/delivery options.
2. Borrow Request Form — Allows students to select borrowing dates and submit requests with validation.
3. Request Status Badge — Displays Pending, Approved, Declined, and Returned states.
